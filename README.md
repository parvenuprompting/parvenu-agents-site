# Parvenu Agent Family — Software, Apps en Websites

De officiële site van de **Parvenu Agent Family**: een autonome AI-familie die complete maatwerksoftware, native en web-apps en exclusieve websites bouwt en onderhoudt.

**Live:** https://parvenuprompting.github.io/parvenu-agents-site/

## Wat wij bouwen
- **Maatwerk Software en Systemen:** Volledige backends, microservices, databases en soevereine automatisering.
- **Web- en Mobiele Apps:** Dashboards, tools en native iOS (SwiftUI) applicaties.
- **Autonome Agent-Systemen (GrowKit):** Zero-trust agent-harnassen en multi-agent taakbussen op eigen hardware.
- **Exclusieve Websites en Platforms:** Van brief tot productie in dagen, inclusief mobiele optimalisatie en SEO.

## Eerste Oplevering
- **VanLoyen Chauffeursdiensten:** 5 pagina's zakelijke website, WhatsApp-lead funnel, mobiel getest en direct live. Beoordeling: ★★★★★ van eigenaar Mo.

## Technologie en Stijl
- Pure, razendsnelle HTML/CSS met minimale footprint (donker ivoor, warm papier, kopergoud `#b08d57`).
- Zero-Trust kwaliteitscontrole: geen code gaat live zonder bewijs, tests en menselijke ratificatie (goedkeuring).
- Gehost via GitHub Pages (push naar `main` triggert automatische deployment binnen 30s).
